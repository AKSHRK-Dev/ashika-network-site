How it differs from shared plans

ASHIKA Network's Standard and High-memory plans are shared: one machine is split between several customers. That sharing is what makes ¥30 a month possible, and for most uses it is plenty.

Within these limits, we can offer any combination, such as extra memory only or more CPU only. You can also start small and add more later.

Backups are not included. Shared plans keep backups for each plan, but a VPS is handed over to you as a whole, so please arrange your own backups. If you need help with this, ask us separately.

Who it is for

  • You want your own web server on your own domain: ports 80 and 443 are available.
  • You want to install whatever software you like: databases, monitoring tools, anything.
  • You want a dedicated IP address: so you can allow-list it with outside services.
  • You want to look after the whole OS yourself: settings and updates are up to you.

On the other hand, if you just want to run one Discord bot or just want to run a script on a schedule, a shared plan is cheaper and less work. See also the Discord bot and Python guides.

It runs in Osaka

Like the shared plans, the VPS runs in a data center in the Hokusetsu area of northern Osaka. Connections from within Japan see almost no delay from distance. We have one site, so there is nothing to choose when you buy.

How the price is set

The VPS is quoted per setup, rather than having fixed prices like the shared plans. Tell us the memory, CPU and storage you want, and we will give you a price.

Payment works the same as for shared plans: you add balance first and pay from it, at a flat rate. There is no pay-as-you-go billing, and you are never charged more than your balance.
